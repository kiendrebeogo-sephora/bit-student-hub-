# BIT Student Hub

Centralized student portal for Burkina Institute of Technology.

## What it does
- Student registration with grades, payments and announcements
- Input validation with try/except
- Object-Oriented Programming with inheritance

## Classes
- User (parent) : base user with name, email, admin status
- Student(User) (child) : adds grades, tuition payments, GPA

## Concepts covered
- Part 1 : Data types (str, int, float, bool), 10+ inputs, f-strings, validation
- Part 2 : Inheritance — Student inherits from User
- Part 3 : Magic methods — __str__, __eq__, __len__
- Part 4 : Decorators — @property, @classmethod, @staticmethod

## How to run
python bit_student_hub.py
